API Endpoints
List Products: Create an API endpoint to list all products.

Retrieve Product: Create an API endpoint to retrieve a specific product by its ID.

Filter Products: Add filtering options for:

Price range: Filter products based on a minimum and maximum price.

Category: Filter products by category.

Availability: Filter products based on availability (available or not available).

Sort Products: Implement sorting options for:

Price: Sort products by price in ascending or descending order.

Name: Sort products by name in alphabetical order.

Advanced Querying: Allow users to combine filters and sorting in a single request.
